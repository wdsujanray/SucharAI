Fig 3.4.9 -- Final SucharAI Application
----------------------------------------

+----------------------------------------------------------------+
|                         SucharAI                               |
|----------------------------------------------------------------|
| Sidebar                                                        |
|  - conversations        Main workspace                         |
|  - search               - AI chat                              |
|  - archive              - object detection                     |
|  - settings             - Google Lens source links             |
|  - file converter       - document conversion                 |
|                         - responsive mobile layout             |
|----------------------------------------------------------------|
| React frontend -> TypeScript backend -> AI, Firebase, database |
+----------------------------------------------------------------+

User flow:

  Open app
      |
      v
  Authenticate or use available offline mode
      |
      v
  Start chat / upload file / detect object / convert document
      |
      v
  Frontend sends request to backend
      |
      v
  Backend calls database and AI/external services
      |
      v
  Result appears in the responsive SucharAI interface
