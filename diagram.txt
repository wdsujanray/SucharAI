Fig 3.4.6 -- Python AI Processing and Deployment
-------------------------------------------------

The repository now includes a Python FastAPI AI processing service alongside
the TypeScript/Express application backend. The Python service is deployed
through Docker Compose and reads GEMINI_API_KEY from the environment.

+---------------------+       HTTP/JSON       +--------------------------+
| backend/server.ts   | ------------------->  | backend/app.py           |
| TypeScript gateway  | <-------------------  | Python FastAPI AI service|
+---------------------+                       +------------+-------------+
                                                           |
                                                           v
                                              +--------------------------+
                                              | ai_engine/processor.py   |
                                              | Gemini chat and vision   |
                                              +------------+-------------+
                                                           |
                                                           v
                                              +--------------------------+
                                              | Model runtime / CPU or   |
                                              | GPU deployment           |
                                              +--------------------------+

Python service endpoints:
GET  /health
POST /api/ai/chat
POST /api/ai/object-detection

Deployment:
docker compose up --build backend
Local development: uvicorn app:app --app-dir backend --reload --port 3001

User flow:

  Open app
      |
      v
  Authenticate or use available offline mode
      |
      v
  Start chat / upload file / detect object / convert document
      |
      v
  Frontend sends request to backend
      |
      v
  Backend calls database and AI/external services
      |
      v
  Result appears in the responsive SucharAI interface
